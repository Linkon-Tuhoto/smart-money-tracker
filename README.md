# Money Tracker 

**Take control of your money, one transaction at a time.**

Money Tracker is a Kenyan-focused personal finance platform designed to help individuals understand, organise and manage their money.

The platform focuses on everyday financial activities, particularly M-Pesa transactions, making it easier to track where money comes from, where it goes and how it is spent.

## Core Features

- **M-Pesa Integration:** Import M-Pesa transaction messages and extract financial information.
- **Income & Expense Tracking:** Record and organise incoming and outgoing money.
- **Transaction Categorisation:** Classify transactions to understand spending habits.
- **Budget Management:** Set category-based budgets and monitor spending.
- **Financial Analytics:** View monthly income, expenses and category breakdowns.
- **Spending Insights:** Understand financial habits and identify areas where spending can be reduced.
- **Multiple Payment Methods:** Track M-Pesa, cash, bank and other payment methods.

## Technology Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- Recharts

## Project Goal

To make personal financial management more accessible and practical for Kenyans by building a platform that understands local money movement, especially M-Pesa transactions.

Money Tracker aims to turn ordinary transaction records into meaningful financial information that helps people make better financial decisions.
